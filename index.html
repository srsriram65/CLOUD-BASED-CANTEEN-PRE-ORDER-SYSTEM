CSE Mini Project

Cloud Computing Concepts Demonstrated

This mini-project demonstrates serverless cloud database integration and live updates. The cloud components include:

  • Firebase Authentication: Secure user accounts and access tokens.
  • Cloud Firestore: Centralized real-time document storage for orders & menus.
  • Firebase Storage: Cloud asset storage for food images uploaded by admins.
